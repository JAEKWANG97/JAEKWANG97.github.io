메일 패치를 제출한 Linux Kernel 사례

10기 기록에는 KUnit 테스트 도구의 출력 처리와 kselftest IPC msgque 테스트를 수정하여 메일 패치를 제출했다는 보고도 있습니다. GitHub PR이 아닌 경로이므로 위 176개 저장소 집계와 분리했습니다.

패치 제출 보고와 병합 확인은 다릅니다. 공개 메일 아카이브의 본문은 봇 확인 화면으로 검증하지 못했으며, 병합 성공 사례로 집계하지 않았습니다.

집계 범위와 상태 해석

  • 10기 게시판의 원글·답글과 기여 공유 기록을 검토한 뒤 공개 PR의 대상 저장소·상태·날짜를 대조했습니다. Discord 원문·화면·참여자 개인정보는 게시하지 않았습니다.
  • 공식 모임 기간 외에 준비 활동과 종료 후 보고도 포함합니다. Traefik은 2월에 보고한 사례로 목록에 표시했습니다. 176개를 3주 안에 새로 제출하거나 병합한 수치로 해석하지 않습니다.
  • 개인 포크 안의 검토용 PR과 다른 사람의 기존 PR을 참고한 기록은 제출 대상에서 제외했습니다. 기여모임 종료 후 Langfuse Python·TanStack CLI·Vite 한국어 문서로 새로 확장한 별도 사례도 이 176개에 더하지 않았습니다.
  • 하나의 생태계에 여러 저장소가 있으면 각각 집계합니다. 게시글 표제 대신 실제 PR 대상 저장소를 기준으로 정리했습니다. 문서·번역·테스트 변경을 본체 기능 개발로 일괄 해석하지 않습니다.
  • 상태는 대표 PR의 조사일 현재 GitHub 표시입니다. Closed만으로 반려·미반영으로 판단하지 않습니다. 예를 들어 Spring Batch #5208은 Closed이지만 별도 반영 커밋을 확인했습니다.
  • 삭제된 글·DM·첨부 이미지 속 텍스트·외부 문서 전체를 조사한 것은 아닙니다. 공개 제출 근거를 확인하지 못한 대상이 곧 기여하지 않은 대상이라는 뜻도 아닙니다.
